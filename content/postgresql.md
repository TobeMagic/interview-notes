# PostgreSQL

不按 MySQL 题号逐条翻译。和 MySQL 的差别本身就是题。两套后端共用这篇。

答案不在这里。大厂公开面经里 PostgreSQL 原题比 MySQL 稀，题目按机制对照来写。

## MVCC、隔离级别、VACUUM

并成一节。

要写的题：

1. 一行上的 `xmin` 和 `xmax` 表示什么。旧版本在表里，不在 undo。
2. 默认是读已提交。语法上的读未提交实际等于读已提交。
3. 可重复读用的是事务开头的快照。和 MySQL 可重复读里 UPDATE 的当前读不一样：这里并发更新同一行可能直接失败，要重试。
4. 写偏斜是什么。可串行化怎么让其中一个事务失败。
5. 长事务为什么让表膨胀。`VACUUM` 清的是什么，为什么有时清不掉。

## WAL

并成一节。

要写的题：

1. 提交时先落的是哪份日志。数据页可以后刷。
2. 为什么没有 MySQL 那种 redo 和 binlog 的两阶段提交。
3. 检查点把恢复的起点放在哪。`full_page_writes` 防的是页写了一半。
4. 流复制和逻辑复制各读 WAL 的哪一种用法。

## 索引

B-tree、GIN、GiST、BRIN 并成一节。覆盖索引要带上 Visibility Map。

要写的题：

1. 等值、范围、JSONB、按物理顺序的大表，各用哪种索引。
2. Index Only Scan 为什么有时还是要回表。Visibility Map 没跟上时发生什么。

## EXPLAIN

单独一节。

要写的题：

1. `EXPLAIN` 和 `EXPLAIN (ANALYZE, BUFFERS)` 差在会不会真的执行。
2. 估计行数和实际行数差很大时，先看统计信息。
